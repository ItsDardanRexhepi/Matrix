Become a Plugin Developer

The 0pnMatrx plugin system is open. Plugins are Python packages. The plugin loader (runtime/plugins/loader.py) can import a package from plugins/installed/, but nothing in the gateway calls it: placing a package there runs nothing today. The marketplace lists plugins and does not install them.

Paid plugin sales are not live yet. Nothing on the platform can complete a paid plugin purchase or pay out its revenue.

📖 Read the Plugin Development Guide

Submit Your Plugin

Submitting is an authenticated API call, so this page cannot make it for you. Send POST /marketplace/plugins/submit to a gateway with its API key (Authorization: Bearer <key>) and a JSON body with name, description, repository_url and author. The listing is stored with status pending. This gateway has no route that approves or activates a listing, so a submitted plugin does not appear here on its own.

💰

Revenue Sharing

Paid plugin sales are not live yet: there is no purchase path and no payout. When they are, the platform commission is the operator's configured rate — the published Terms of Service state 10% — and a sale through Apple In-App Purchase also pays the App Store's commission before any split. Nothing is settled to a wallet today.
